ReadyCode Reader demo

Ask a big PDF, Word or Excel file specific questions and see exactly what your AI would read: only the passages that answer, with where they came from, or an exact count from every row of a spreadsheet. Your file is read in this browser and never uploaded.

Drop a .pdf, .docx, .xlsx, .txt, .md, .csv or .json file here (up to 500 MB)

Used to check passages with the Jev decision model. For each question, this page sends the question and the short candidate passages or rows it found (up to about 20) straight to OpenRouter; your whole file is never sent. The key stays in this page's memory: it isn't saved, and it never reaches ReadyCode. A check costs about $0.0004 per question. Privacy · No key? Get one at OpenRouter.

Reader finds particular facts. In a spreadsheet, counts, rankings, totals and "list everyone who…" are calculated exactly from every row. If Reader can't be sure it has understood a calculation, it says so and shows the plan instead of guessing.

Choose a file to start.

Reader is free and open source. Install it in Claude Code, Cursor or Codex so your AI reads big files this way on its own. Sign up at ReadyCode for Reader updates, new tools, and early access to the hosted version (no key or setup).
